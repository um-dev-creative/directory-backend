# Project documentation map (user guide)

Where to find what, depending on who you are.

| You are | Start with |
| --- | --- |
| Business analyst / product owner | `docs/BA_QUICK_REFERENCE.md`, then `docs/BA_VISUAL_SUMMARY.md` and `docs/COMPLETE_PROJECT_DOCUMENTATION_FOR_BA.md` |
| New developer | `README.md`, `docs/PROJECT_DOCUMENTATION.md`, `docs/DOCUMENTATION_INDEX.md` |
| Operator | `docs/user-guide/*.md` (one guide per feature), `variables_reference.md` |
| Reviewer | `docs/BUILD_VALIDATION_REPORT.md`, `CHANGELOG.md` |

Every feature has a user guide in `docs/user-guide/` and a technical guide in `docs/technical/`; the `CHANGELOG.md` summarises each change in English.
Open work items live in `issues/`.
