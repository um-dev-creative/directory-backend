# Languages (Spanish, English, Canadian French)

The API answers in English, Spanish or Canadian French. You choose the language with the standard `Accept-Language` header.

## How to choose the language

| You send | You get |
|---|---|
| nothing, or an unsupported language (`de`, `ja`) | English (`en`) |
| `en`, `en-US` | English (`en`) |
| `es`, `es-MX` | Spanish (`es`) |
| `fr-CA`, `fr`, `fr-FR` | Canadian French (`fr-CA`) |
| `de, es;q=0.5` | Spanish: the first supported language by preference wins |

Every response carries `Content-Language` with the language used (`en`, `es` or `fr-CA`).

## What is translated

- The explanation of an error, in the `message-error` (and `message`) response header. Example: with `Accept-Language: es`, a missing business answers `404` with `message-error: Negocio no encontrado.`
- The name of the categories (`GET /api/v1/categories`, `/api/v1/categories/{id}`, `/api/v1/categories/parent/{id}`). Each category now also has a `locale` field with the language of the response. If a category has no translation yet, you get its original name.

A message that has not been translated yet is sent in English; nothing else changes in the responses.

## Example

```
GET /api/v1/categories/3f1c...
Accept-Language: fr-CA
```

```json
{ "id": "3f1c...", "name": "Restaurants", "description": "...", "locale": "fr-CA", "active": true }
```
